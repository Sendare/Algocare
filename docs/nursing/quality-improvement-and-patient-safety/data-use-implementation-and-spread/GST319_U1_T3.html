Run Charts

Introduction to Run Charts in Healthcare Quality Improvement

A run chart is a simple yet powerful graphical tool used in healthcare quality improvement to display data over time. By plotting clinical metrics sequentially, nurses and quality teams can easily visualize trends, shifts, and patterns in patient care delivery. Unlike complex statistical process control charts, run charts require no advanced mathematics, making them accessible for ward-level audits and clinical meetings across Nigerian hospitals. They help clinical teams quickly determine whether changes implemented in a unit—such as a new handwashing protocol or a modified patient handover checklist—are actually leading to measurable improvements.

Basic Elements of a Run Chart

Every standard run chart consists of specific components arranged on a two-dimensional grid:

  • Vertical Axis (Y-axis): Represents the operational metric, measurement value, or percentage being tracked, such as infection rates or waiting times.
  • Horizontal Axis (X-axis): Represents the time sequence, such as days, weeks, months, or shifts.
  • Data Points: Individual values plotted for each specific time period.
  • Connecting Lines: Straight lines joining consecutive data points to show the directional flow.
  • Median Line: A solid horizontal line dividing the data points so that roughly half fall above and half fall below it.

Steps for Constructing and Plotting Data Over Time

Building an effective run chart requires a systematic approach to gathering and displaying clinical information.

  1. Define the Goal: Clearly state the clinical quality issue or process you want to improve.
  2. Select the Measure: Choose a reliable, easy-to-collect metric, such as the daily incidence of pressure ulcers.
  3. Gather Baseline Data: Collect consecutive data points over a meaningful timeframe, usually at least 10 to 12 time periods.
  4. Draw the Axes: Label the vertical axis with your measure and the horizontal axis with the time sequence.
  5. Plot the Points: Place a dot for each data value at the intersection of the corresponding time and measurement.
  6. Calculate and Draw the Median: Find the middle value of all data points and draw a horizontal reference line across the chart.

Distinguishing Common Cause from Special Cause Variation

All healthcare processes experience natural fluctuations. Understanding these variations prevents clinical teams from overreacting to normal day-to-day noise.

  • Common Cause Variation: The natural, predictable variation inherent in a stable process. It represents routine operational background noise.
  • Special Cause Variation: Non-random variation caused by specific, identifiable events, such as a sudden strike, equipment breakdown, or the introduction of a new clinical guideline.

Run charts help separate these two types of variation, guiding nurses on when to investigate an anomaly and when to leave a stable process alone.

Four Rules for Interpreting Run Charts

To determine if a true change has occurred in a process, quality improvement experts use four specific decision rules based on probability.

  1. A Shift: Six or more consecutive data points all above or all below the median line. (Values right on the median do not count and reset the count).
  2. A Trend: Five or more consecutive data points all going consistently up or all going consistently down.
  3. Runs (Too Many or Too Few): The total number of times the data line crosses the median line. Too few or too many crossings indicate non-random behavior.
  4. An Astronomical Data Point: A data point that is so radically different from the rest that anyone looking at the chart would consider it an outlier.

Application of Run Charts in Nursing and Patient Safety Initiatives

Run charts are practical tools applied across various clinical domains in Nigerian healthcare settings. Ward managers use them to monitor rates of hospital-acquired infections, track compliance with surgical safety checklists, and evaluate waiting times in busy outpatient clinics. By displaying these charts on staff notice boards, nurse leaders foster transparency and engage frontline staff in problem-solving. When a run chart shows a positive shift following a new intervention, it provides tangible evidence that motivates the healthcare team to sustain their efforts toward safer patient outcomes.
